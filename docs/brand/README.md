# WorkSets visual identity

`worksets-concept.png` is the visual reference generated for the first WorkSets alpha. It is not shipped in the application UI. The production mark is recreated as deterministic SVG and exported to the Windows icon formats.

## Direction

- Three overlapping, rounded workspace cards form a subtle upward `W`.
- The middle card uses dark ink; the side cards use coral and sage.
- Small white status dots reinforce the idea of separate workspaces.
- The mark must remain recognizable at 16 px and must not resemble the four-pane Windows logo.

## Palette

- Cream: `#FFF8F2`
- Ink: `#292522`
- Coral: `#B5482E`
- Sage: `#5F7467`

## Generation brief

The concept was generated with the built-in image-generation workflow using the `logo-brand` use case. The brief requested a flat, vector-friendly identity board for a warm Windows productivity app, the exact text “WorkSets” and “by Tracht Digital Solutions”, icon-size studies, accessible contrast, and no gradients, 3D treatment, Windows-logo imitation, extra text, or watermark.
